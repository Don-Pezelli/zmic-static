# ZMIC Static Website

Static mirror of `https://zmic.de/` for upload to a new web host.

## Upload

Upload the contents of this folder to the web root of the new host:

- `index.html`
- all page folders, for example `kompetenz/`, `methoden/`, `leistungen/`
- `css/`
- `images/`
- `yaml/`

No build step, CMS, database, or server-side runtime is required.

## Local Preview

Open `index.html` directly in a browser, or serve this folder with any static web server.
